# 📋 Portal de Propuestas NN

**Portal de propuestas personalizadas · Nationale-Nederlanden · Fede Fontanals**

Herramienta comercial para enviar propuestas visuales y personalizadas por enlace directo a clientes.

---

## 🚀 Cómo usar

Copia esta URL y cambia los parámetros según el cliente:

```
https://fedefonta08.github.io/propuestas-nn/?nombre=NOMBRE&producto=PRODUCTO&prima=PRIMA
```

### Parámetros disponibles

| Parámetro | Valores | Ejemplo |
|-----------|---------|---------|
| `nombre` | Nombre del cliente | `Salvador` |
| `producto` | `autonomo` / `familia` / `futuro` | `autonomo` |
| `prima` | Prima mensual estimada | `39,94 €` |
| `capital` | Capital total asegurado | `266.000 €` |
