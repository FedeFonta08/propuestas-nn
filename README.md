## Límite de seguridad

Este repositorio es público. Por tanto, no se permite versionar ni desplegar aquí:

- contactos, teléfonos, correos, fechas de nacimiento, notas o perfiles de clientes;
- exportaciones de CRM, hojas de cálculo con datos reales o copias de seguridad;
- tokens, credenciales OAuth, claves API o identificadores que permitan acceder a sistemas internos;
- paneles que consulten o modifiquen el CRM desde el navegador;
- automatizaciones que generen páginas con datos personales;
- código operativo de correo, Google Drive, Google Sheets, Calendar o Contacts.

El CRM, las automatizaciones y los datos de agentes deben residir en servicios privados con autenticación individual, autorización por rol, registro de accesos, cifrado y una política de conservación.

## Desarrollo seguro

Antes de publicar cambios:

1. Utiliza únicamente datos ficticios.
2. Revisa que no haya credenciales ni endpoints privados.
3. Abre una pull request y espera a que finalicen los controles automáticos.
4. Comprueba que la página no transmite información personal a terceros.

Las vulnerabilidades no deben comunicarse mediante issues públicos. Consulta [SECURITY.md](SECURITY.md).
