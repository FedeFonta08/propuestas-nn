# Política de seguridad

## Alcance

Este repositorio y su publicación en GitHub Pages solo pueden contener información destinada al público.

No publiques datos personales, exportaciones de CRM, credenciales, endpoints internos ni herramientas que accedan a sistemas privados desde el navegador.

## Comunicar una vulnerabilidad

No abras un issue público.

Utiliza la opción **Security → Report a vulnerability** del repositorio para iniciar una comunicación privada con el propietario. Incluye:

- archivo o URL afectada;
- impacto observado;
- pasos mínimos para reproducirlo;
- propuesta de mitigación, si la conoces.

No descargues, copies ni difundas datos personales durante la verificación.

## Respuesta

Las incidencias que puedan exponer credenciales o datos personales deben contenerse de inmediato: retirar la publicación, revocar accesos, conservar evidencias mínimas y evaluar las obligaciones de notificación aplicables.
